# AI Safety Monitor Workflow

## Objective

Develop an AI-based Workplace Safety Monitoring System using Computer Vision and Real-time Alerts from project planning to thesis defense.

---

# Workflow Phases

1. Research
2. Architecture
3. Dataset
4. Training
5. Evaluation
6. Improvement Loop
7. Deployment
8. Testing
9. Thesis
10. Reporting
11. Presentation

---

# Rules

Never skip a phase.

If a phase is incomplete,
continue that phase first.

Always update state.md.

Always recommend the next action.

Whenever new experiment results exist,
automatically update the thesis draft.
